## 2026-06-05 — S3: `harness-init` scaffold procedure live (plan 0003)

A top-level agent runs **detect → create-if-absent / merge-in-fence → report** on every write — **never-clobber is the load-bearing safety invariant**; a re-run is a **provable no-op** (`git status` shows zero changes). - **Two durable conventions declared** (contracts re-run **and `/harness-update`** depend on — decided deliberately, not incidentally):
  - **Managed-stamp:** first line of every *copied* file — markdown `<!-- agentic-dev-harness@{VERSION} managed — do not edit; run /harness-update to refresh -->`, Python `# agentic-dev-harness@{VERSION} managed — …`; `{VERSION}` = `plugin.json.version`. The greppable token **`agentic-dev-harness@<semver>`** is the contract: init's copy-if-absent detects a managed copy by `agentic-dev-harness@`; `/harness-update` regexes the semver to compare. Source modules stay pristine (unstamped, editable); the stamp is added **on copy**.
  - **CLAUDE.md `harness:managed` fence:** `<!-- harness:managed:start -->…:end` (mirrors the `harness-audit:overview`/`:backlog` fences) — replace-only-inside / human-owned-outside. **No volatile content inside the fence** → re-run byte-identical (so "zero diffs on run 2" holds). The seeded **Current scope** + **detected-tooling** blocks live **outside** the fence (local, editable, never overwritten).
- **S3 defines `/harness-update`'s input contract** (so the later slice doesn't redesign it): parse the `agentic-dev-harness@<semver>` stamp → overwrite managed files with newer → re-merge the two hooks. Init only copies/seeds-if-absent; the version-overwrite is update's job.
- **Current-scope → the adopter's `CLAUDE.md` `harness:` section** (a local, non-managed spot that survives `/harness-update`), **not** the old "append to `ENGINEERING_STANDARDS.md`" (that file is a managed copy update overwrites — CR-2). Fixed the contradicting line in the copied `docs/ENGINEERING_STANDARDS.md` + aligned `docs/standards/README.md` (these ship into every adopter, so higher-stakes than a normal doc tweak).

- **Globs set in pairs:** init sets **both `INCLUDE_GLOBS` and `STALE_PATTERN`** in the **copied** script (setting only the former leaves the staleness check dead — the script requires the two stay in sync); for an unmappable ecosystem, a conservative broad glob + report. **No edit to this repo's source script** (deferred a DRY `--list` mode — it edits the untested gate, blocked on backlog Tier-1 #1).

Compose = **detect + record only, never install/reconfigure** the adopter's tooling. settings.json hook-merge: parse JSON (absent→`{}`), **fail loud + report-and-skip on malformed**, append into existing arrays preserving user hooks, idempotency keyed on a `command` containing `check_architecture_tree.py`, write the `${CLAUDE_PROJECT_DIR}`-rooted command + the step-1-detected interpreter.
