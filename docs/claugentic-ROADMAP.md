### Later / Ideas

- **`harness`** — **Split `skills/init/SKILL.md` into a lean skill + an on-demand reference (0044 §5 candidate B, deferred to 0.7.0).** `init` is 74.7 KB ≈ 40% of the skills corpus and is loaded whenever init is merely *considered*, not only when it runs; moving the managed-set table, the four upsert verdicts, the wrapper/husky templates and the Solo divergences into an on-demand reference would cut ~45 KB from that always-considered context-load (it is context-load, NOT download payload — both files ship). **The reason it waits:** it is a structural refactor of the contract-densest command, touching ~7 test-pin sites (`test_precommit_wrapper.py`, `test_check_shipped_content.py`'s managed-set region-scope, `test_check_doc_budgets.py`'s one-json-fence assertion, `test_build_release.py`, `test_adopter_pointer_integrity.py`) plus new `${CLAUDE_PLUGIN_ROOT}`-reachable payload membership — not something to rush beside a release an adopter is about to depend on. The recommended sequence (per `groundwork/skills-merged.md` §5): a description-parity gate first, then the split, then the wrapper de-duplication (candidate A, −3.7 KB, converts 5 parity pins from pinned to structural). **Pull-in evidence:** none needed — user-deferred at the 0.6.0 ship, do it as 0.7.0.

- **`harness`** — **The suite is a run-gate, so a docs-only commit can land it RED and nothing says so.** The commit-time wrapper chains exactly two gates (architecture-tree, doc budgets); "full suite green" is a Definition-of-Done obligation attached to a **slice** Land. **Measured 2026-08-20 (plan 0044):** a Stage-2 plan commit wrote a live eval answer-key id into its own plan file, turning the containment scan red; **six successive commits sat on `main` red** (`73ecf09`..`4fd38ef`, five of them plan-only) and the S1a implementer found it before writing a line. Two candidate shapes: chain a **fast content-scan gate** into the wrapper (the scan is 13 tests / 1.3 s but lives in `tests/`, which the release strips — a chained gate must be a `scripts/` sibling, per *one gate, one invariant*), or make suite-green an obligation of **every** commit, not only a slice's. **Pull-in evidence:** a second occurrence, or any commit class that reaches `main` without a suite run.
