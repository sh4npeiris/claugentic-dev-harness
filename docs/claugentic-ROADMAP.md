The forward backlog for the harness itself. Work runs through `docs/claugentic-WORKFLOW.md` (triage → plan → review → spec → approve → implement → verify → land → retrospect), sliced so each unit lands complete with no tech debt. Tangents land here, never silently into the current change.

This file is the product's own roadmap, not a generated audit — an adopter generates theirs by running the `/claugentic-dev-harness:audit` + `/claugentic-dev-harness:product` gap fences.

Not built.
- **`harness`** — **Release/init-contract completeness gate (generalizes the `plugin.json:agents` pin).** Today `check_shipped_content.py` catches the *symptoms* (a shipped doc citing a stripped-uncreated **path** → hard fail; a stranded agent/skill **namespace** token → hard fail), but its `_INIT_CREATES` allow-list (`:103-112`) and the `test_build_release.py` ship-pins are **hand-maintained**, so *under-wiring* a new user-file isn't fully fail-loud: **(a)** a new agent left out of `plugin.json:agents` has **no gate** (silently won't load); **(b)** a new seed (`_X.md`→`X.md`) whose created twin isn't added to `_INIT_CREATES` false-flags as a dangle or slips; **(c)** a missing ship-pin isn't self-caught. Fix = **one referential-closure run-gate** (CI + DoD, not a hook): assert **NEEDS ⊆ HAS** (HAS = shipped ∪ init-created; NEEDS = everything shipped content references) with **both sides DERIVED from the filesystem + naming conventions** (the `_X.md`→`X.md` convention self-derives init-creates — **no hand-kept `_INIT_CREATES`**); a file matching **no** convention **forces a one-time role declaration** (forgot-to-register fails LOUD). Derive the derivable lists (`_INIT_CREATES` · `KNOWN_MODULES` · agents-list); shrink the irreducibly-*semantic* ones (`DEV_ONLY` judgments · the allow-lists) to conventions + a gate-verified **declared-exceptions** set. Type-agnostic; evolves `check_shipped_content.py` (belt-and-suspenders = a round-trip *build→init→diff* test). **Honest limit — gates WIRING, never SEMANTICS** (seed-content currency / category judgment stay model-upheld). Companion to `0030`'s `_CHARTER.md` (the first new seed). (User's release-robustness question, 2026-06-29.)
