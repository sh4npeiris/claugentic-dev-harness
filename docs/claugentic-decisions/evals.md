# The evals (measurement instruments, not gates)

Part of the decisions ledger — index & filing rule: `docs/claugentic-DECISIONS.md`. Do not link this file from outside the index.
- **The BUILD-path eval exists because the audit-path eval measures DETECTION, and the owner's goal is OUTPUT (2026-08-20, plan 0044 S1a).** The names-only ablation held audit recall at 10/10 (one run, 2026-08-20, measured in-session and **not** recorded as an `eval/BASELINE.md` entry — the ledger's 2026-08-20 entry is the separate post-thinning run at 9/10) — evidence, not proof, that the catalog's *audit* product is boundaries and enumeration rather than knowledge, and **evidence about one path only**: the same catalog is the implementer's authoring checklist, and no instrument had ever measured what the implement path SHIPS. `eval/fixture-build/` is that instrument. One question per run — *did swapping catalog variant A for variant B change what the implement path actually ships?* — with a fixed brief, a frozen approved plan slice copied into each run worktree (so the shipped `implementer` contract is used **unmodified**, with the run's scoping — writes confined to `out/`; the architecture tree and this checkout's gate scripts out of scope — delivered through the contract's own plan-file channel rather than a wrapper-prompt departure), ten trap probes, a held-out functional suite, and a spec-compliance pass scored **separately** so an interface drift can never masquerade as a quality delta. **The only difference between arms is the bytes inside `docs/claugentic-standards/`.** Procedure and thresholds: `eval/BUILD_BASELINE.md`; results: `eval/BUILD_ENTRIES.md`. Never a CI gate — model-upheld, run on demand.
- **Day-one procedure/entries SPLIT, and its ID HALF is mechanically held (2026-08-20).** The sibling eval carries its procedure directly above two answer keys and records that as a **killable half**; the build eval is split at birth into `eval/BUILD_BASELINE.md` (procedure, no answers) and `eval/BUILD_ENTRIES.md` (answer-bearing). Held, not just intended: the procedure file is deliberately **absent** from the containment scan's allowlist, so an answer **naming a trap id** turns the suite red — **an answer in paraphrase stays green, and that half is model-upheld.** Shared chassis mechanics, including the run-time deletion CLASS, have **one home in `eval/BASELINE.md`** and are cited from the build eval, never copied (a second copy was proposed and refused, then landed anyway in non-equivalent words and had to be collapsed). **Adding an exam means teaching the other exam's deletion class about it, in the same change.** The class is broad on the ANSWER-BEARING axis and **non-transitive** on the names-a-deleted-path axis: measured 2026-08-20, closing the second axis transitively reaches 98 paths and deletes `docs/claugentic-standards/` — the treatment the eval exists to measure.
- **A decision comparison is ONE sitting, ONE base commit, interleaved — or it is invalid (2026-08-20, Stage-3 R1(i)).** An arm measured in an earlier slice confounds the catalog cut with tier drift and with every commit landed between, so the first arm-A outing is a **shakedown, never a decision input** and the comparison re-derives arm A at ~50% more builder spend. Procedure: `eval/BUILD_BASELINE.md`.
- **The instrument verifies itself before it may measure anything, and the anti-tuning rule is DEFECT-vs-TUNING (2026-08-20).** A calibration pair (clean reference + at least one mutant per trap, as overlays) must pass before any sitting, which is what discharges each mechanical row by **resolution** rather than by its tag being typed. **A probe that demonstrably does not measure what its row claims is a DEFECT: fix it, record it, re-run the calibration. A probe is never adjusted to move an arm's score, and the reference is never touched** outside the recorded both-arms-saturation allowance. Two mechanics that look like mistakes and are not: a mutant may carry a second file so its own suite is consistent with the defect it carries, and `H` and the `delta-F` threshold are pinned together, re-pinnable only together. Detail: `eval/BUILD_BASELINE.md`, `eval/fixture-build/TRAP_MANIFEST.md`.
- **A trap is admissible only by HARM, and the judged rows are kept (2026-08-20).** Every row names the bug a person would file; a trap defensible only as *“the catalog says so”* is inadmissible, because the honest residual is that traps and catalog share subject matter — the defense is that the checks measure the **failure**, not the vocabulary. **Dropping the judged maintainability row was proposed and refused**: it is the prose-sensitive dimension the audit-path ablation lost. Where a mechanical check genuinely discriminates the row is `[D]`, never `[J]` for symmetry. Rule text: `eval/fixture-build/TRAP_MANIFEST.md`.
- **The instrument may not read the treatment; the brief may not coach the answer (2026-08-20).** Two one-way rules, both chosen deliberately and both with owning sources: the sweep never reads the catalog (rule and its pinned literal-half residual: `tests/test_eval_trap_manifest.py`), and the builder-visible artifacts never name a remedy (rule, denylist rationale and the recorded `commit`/`except` word costs: `eval/fixture-build/TRAP_MANIFEST.md`). The choice worth not re-litigating is the trade: **the brief pays in phrasing rather than the scan carrying exemptions**, and the one hazard sentence the brief is allowed needs none. Do not add one.
- **Thresholds are pre-registered and one phrasing is forbidden (2026-08-20).** Every threshold was fixed before any arm ran, and the functional floor leads the verdict; the numbers, the floor clauses and the saturation carve-out live in `eval/BUILD_BASELINE.md`. The durable choice: a clear result is **“no regression detected at this K”** — **never** equivalence shown, and **never** predicated of the cut itself (*“a non-regressing cut”* is the forbidden reading). An ambiguous verdict defers the cut; it never forces one.
- **The eval instrument is LINTED like everything else; only defective material is excluded (2026-08-20).** The choice: `eval/` is no longer excluded wholesale — only the directories whose contents are deliberately wrong — so the measurement tooling and the clean reference get the same dead-code and undefined-name coverage as `scripts/`. The directory list and the reason live in `pyproject.toml`'s `[tool.ruff]` block, with one rule exempted there for `checks/*.py` (measured: eight of the seventeen `# noqa` removed in the same change were suppressing a live one). This is what keeps *“a per-line `# noqa` is forbidden”* true inside `eval/` instead of moot there.
- **Do not re-propose (design panel + 2b round, 2026-08-20).** Rejected with reasons, so they are not re-argued: an **audit-as-instrument corroboration layer** (~20-40 agents for zero gate power — survives only as a one-line extension note) · a **20-agent blind pairwise judge panel** (cost without decision power at this K) · **K=1 with an immediate block** (decision-on-noise in both directions, given the coin-flip record of the audit fixture's flakiest seed) · a **convergent-deficit rule** (structurally biased toward false PASS) · **dropping the judged rows** · **reusing the audit fixture's task-tracker domain** (fixture shape would prime a builder) · delivering the brief through the **wrapper prompt** instead of the plan slice · **whole-run sealed arm blinding** · **auto-editing code lines during redaction** (comment lines only; a code line that could identify an arm is FLAGGED for a human, never rewritten — a grader reading altered code is grading something nobody wrote) · a standing **K=1 drift MODE** built into the procedure (reduced to a one-line advisory extension: it may trigger a full comparison, never issue a verdict) · a **separate A-vs-A calibration run** (the intra-arm spread at K=3 is the noise yardstick; **pull-in condition, recorded: a real delta landing ambiguously inside that measured spread**).
