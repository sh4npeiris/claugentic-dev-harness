- **The hook-wired SET is TWO, and `init` delivers + seeds + chains (0041 S7, 2026-08-15).** The doc-budget gate is chained into the shared pre-commit wrapper immediately after the tree gate, in BOTH homes at the same relative position (`run_gate scripts/claugentic-check_doc_budgets.py || rc=1` — **no args**: the gate reads none, and the call-site-args rule is what keeps the wrapper's own scoping claim true). `|| rc=1` is the run-both-and-report seam: neither gate's failure masks the other's message. **Enforcement is presence-scoped, always say so:** hook-enforced only where a wrapper is wired — a `keep-gate-off` repo has none, and a machine with no working Python gets ONE skip notice covering both gates and commits anyway. - **The gate scripts self-anchor to their own repo root at runtime (CWD-independent).** A `_repo_root()` helper derives the root from the script's own location — **never** an absolute/hardcoded path, so it's portable across machines/adopters; **all user-facing output stays repo-relative** (no machine-path leak). The helper is **duplicated, not shared** (the copied tree-check can't import a harness-repo module — each gate is independently self-contained). Stdout/stderr are reconfigured to UTF-8 (em-dashes must not mojibake on Windows cp1252).
- **Warn-and-pass hook posture (user-decided 2026-08-13, 0041 S5).** Infrastructure failure never blocks a commit: broken git passes **silently** (no repo to report into); a missing/broken interpreter (probed `python3` then `python`, floor 3.7) or a missing gate script skips **loudly** (one stderr line) and passes. Only a gate that RAN and failed — or crashes once started — aborts. Advisory on interpreter-less machines: `/doctor` carries an **interpreter-health row** (0041 S6) that replicates the probe exactly — candidates EXECUTED in order, never `command -v`, through `sh` where available — and reports a dead interpreter as a **flag**, remedy in the hook's own register. A chained gate's advisory output rides **stderr** — the wrapper eats stdout (see INVARIANTS). **The posture itself is out of bounds, not refuted (0041 S5 X5)** — warn-and-pass, commit-time-only and default-chain are user decisions; a review round refines their wiring, never re-litigates them.
