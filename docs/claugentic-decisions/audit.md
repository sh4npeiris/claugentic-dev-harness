# The audit (`/claugentic-dev-harness:audit`)

Part of the decisions ledger — index & filing rule: `docs/claugentic-DECISIONS.md`. Do not link this file from outside the index.

- **One thoroughness slider, three notches** (`quick` · `standard` · `thorough`), one uniform pipeline at every notch: **FIND → PRUNE → VERIFY → surface.** All relevant lenses run at *every* level — a lens is never dropped to make a level cheaper; the slider sets the **depth** each lens reads at (`focused` → `deep` → `exhaustive`). `thorough` (named-only, never auto-picked) also runs the **blind-spot sweep** (`lens-reviewer` whole-scope mode) + an **adversarial `yagni-sentinel` prune**.
- **The re-check is universal:** after the prune, the audit attempts to refute **every surfaced finding, all tiers, every level** (one `finding-verifier` per finding). Every backlog item shows one verification tag; the legend carries the not-a-mechanical-guarantee caveat. Identical re-sweeps are retired (**single look per cell**); recall rests on lens breadth + depth.
- **Deterministically bounded + resumable, via INTERLEAVED round-robin cell ordering → no lens starvation.** A finite cell set, one shared backstop `max-cells-per-run` cap (bounds cost + the orchestrator's synthesis context, not per-agent context), `PARTIAL` checkpoints with explicit done/pending lists; findings are never count-capped or silently truncated. `enumerateCells` iterates **dir-OUTER / module-INNER**, so a budget-limited prefix covers EVERY lens's top dir broad-then-deep — when `maxCellsPerRun ≥ lens count` every lens gets ≥1 cell and **whole-lens starvation is structurally impossible** (the ordering IS the per-lens floor; no separate floor pass). **The cap wins**; a `maxCellsPerRun < lenses` run surfaces never-run lenses **loudly** via `lensCoverage`. Re-enumeration is a **pure function of input order**, so `doneCells` reproduces the interleaved tail exactly; this **resume-determinism is the load-bearing invariant** (test-pinned). The **blindspot pseudo-cell stays strictly last.** `lensCoverage` distinguishes **ran-clean** (explicit CLEAN) from **never-ran** (budget-deferred / failed). **Deferred to ROADMAP (YAGNI):** auto-sizing `maxCellsPerRun` + hierarchical roll-up.
- **Fences are regenerate-don't-accumulate:** the audit fences are replace-only-inside, human-owned outside; **no script-generated noise inside a fence** (byte-identical re-runs apart from the stamped audit date). **"Sound on the audited dimensions"** is the explicit terminal signal when Tier 1+2 come back empty — a stop signal, not a treadmill. **Two backlog fences, each regenerate-independently:** the engineering audit writes `harness-audit:backlog`, product gap mode its **own** `harness-product:backlog` — running one **never** touches the other; the **renderer is reused, not forked** (same `renderBacklogFence`, only the marker differs — DRY). The product fence is a **re-derivable projection of the spec against current code** — the durable product layer is `docs/claugentic-PRODUCT_SPEC.md` + the human-owned ROADMAP, **not the fence**; **cross-fence dedup is model-upheld at `build` triage**, not mechanical; product is **backlog-only**. **Fence-conventions are paired-or-explicitly-not:** any future fence addition must check **every** singular "the backlog"/"the fence" reference and either pair it or record the asymmetry on purpose.
- **The "Application source present" predicate is defined once** (audit Phase 1), reused by `init` — a repo of only docs/config/scaffolding is "no application source" (a new-project on-ramp, not an audit target).
- **The eval (`eval/`) is a seeded-defect drift detector, not a quality guarantee.** `eval/BASELINE.md` is the single source of truth for the measurement procedure; the intentional seeded defects **MUST NOT be "fixed"** — fixing them disarms the exam. The no-peeking contract is **prompt-scoped + canary-backstopped**, never a filesystem sandbox; `eval/` is repo-local, never copied. **The answer key stays inside the fixture (2026-08-18, plan 0041 S11):** no tracked file outside `SEED_MANIFEST.md` + `eval/BASELINE.md` may name a seed id (`tests/test_eval_key_containment.py`), and `.claude/plans/` is deliberately **not** exempted — a plan is where an eval re-run gets ordered, so a directory exemption would be a permanent hole in the corpus that matters most. The pin guards the id **token** only; paraphrasing a seed's defect nature leaks the same key and stays model-upheld.
- **Eval scoring: grade with the instrument the baseline used, and record a second instrument as a separate number (2026-07-30, v0.5.0 gate).** The precision proxy is only a drift signal if successive runs are graded the same way. That run's non-seeded findings scored **25/25 neutrally** ("literally true of the code" — v0.1.26's standard) and **19/25** under a refute-first adversarial panel; comparing the latter to a neutrally-graded 100% would manufacture a 24pp "regression" that is an **instrument mismatch, not drift**. So: the **block decision rests on the baseline-comparable instrument**, and a stricter instrument is recorded beside it, labeled, never silently substituted. Corollary, the same rule in the other direction: the recorder's own provisional seed "hit" was **overturned by a 0/3 adjudication panel** and the miss recorded — delegate the judgment-heaviest scoring calls, then adopt the verdict.
- **The finder pipeline + SELECT-before-render gate** (canonical: WORKFLOW → *The finder pipeline*; coverage invariant in INVARIANTS → SELECT re-render). Non-obvious constraints: **SELECT is model-upheld, NOT a mechanical gate**; **skip ≠ reject** (a non-tick is a per-run skip; explicit rejection appends to the rejected-memory fence, never inferred); **commitment (not capture) triggers the plan** (selecting = the Stage-2 trigger); the agent-free **`renderOnly` fast-path** is the only render seam, coverage/run-report full-scope over it (the invariant); **OFFER-BUILD default = leave, never forced**; Bugs-as-3rd-source = build-TRIAGE, not the finder SELECT.
- **`doctor` — the harness-health finder + its treat-boundary (0025 S7; canonical: `skills/doctor/SKILL.md`).** `doctor` checks the **harness's OWN** wiring/ledgers/plans (vs `audit` = your code vs standards), on the shared finder pipeline. **Diagnose is strictly READ-ONLY** — gate scripts by **per-script presence** (run a gate iff its script is present, else N-A) → a **transient** snapshot (NOT a fence) with honest **`[D]`** (exit code) vs **`[J]`** (model-upheld). **Treat fires ONLY on explicit approval, never silent**, and ONLY the **bounded ∧ reversible (git history) ∧ no-architectural-decision** set: delete a landed/cold plan · re-wire the pre-commit hook · apply a doc-condensation diff · tree hygiene. **The doc-condensation treat is safe ONLY because the diff is user-approved before apply (the approval IS the decision gate — NOT because condensation is decision-free).** Anything **substantive** → ROADMAP → commitment triggers the plan → OFFER-BUILD. **doctor REPORTS the Stage-9 "harvest likely skipped" signal; the active harvest is `retrospect-harvester`'s** (no double-build). **No durable doctor reject-memory** (a recurring health issue SHOULD recur).
- **The rejected-findings memory — a dropped audit finding stays dropped.** Dismissed findings live in the `<!-- harness-audit:rejected-findings -->` fence in `docs/claugentic-ROADMAP.md`, **OUTSIDE** the regenerate `harness-audit:backlog` fence (a re-audit must not wipe it; finders read it before rendering and skip listed findings). A **user override of model judgment, not a deletion of evidence** (product mode mirrors it via `<!-- product-critic:rejected-proposals -->`). Detail in WORKFLOW → finder pipeline.
- **The `renderOnly` SELECT seam is decided on the PARSED args, and bypasses `validateArgs` BY DESIGN** (0041 S10a D1, 2026-08-17). A `scriptPath` invocation delivers `args` as a JSON **string** — the only shape `/audit` uses — so a branch testing the RAW value could never fire: the documented call fell through to `audit args invalid`, and a caller re-passing its original args alongside `renderOnly` got a **second full audit** with the whole FIND/PRUNE/VERIFY fan-out. The decision now lives in the pure `auditEntry(rawArgs)` (parse → decide) **inside** the helpers block — everything below `// --- end helpers ---` is unreachable by the extract-and-eval harness, so extracting the decision IS the fix's testability half. Keep the seam **before** `validateArgs` (a `renderOnly` payload legitimately carries no `dial`/`modules`/`scopeDirs`; `renderOnlyResult` validates its own payload at the boundary); the order and the absence of any raw `args.renderOnly` read are both source-pinned.
