- **Review is cross-review by separate specialist agents — independence of context and role, NOT of model.** Distinct roles + clean contexts, each on the most-capable available model (tier by auto-resolving alias). No different-model judge — the honest framing is **structural independence only.** Script runs pin `model: MODELS.judge`; prose runs use agents' `model:` frontmatter. *(An inert legacy cross-model token remains in the engine + test fixtures; fully removing the dormant machinery is a deferred YAGNI cleanup.)*
- **Same-model honesty after the cross-model judge was dropped:** every judge opens with a `RUNNING AS:` self-report naming its **model family**; on **any same-family run** the orchestrator applies the verbatim tag *"same-model review on this run — the judge and the builder are the same model family here."* A spawn error respawns with the default + the tag (**a gate role never becomes unspawnable**); an unrecognized family is *unresolved*, never asserted same-model. Wording lives once in `engine/*.js` (test-pinned).
- **`finding-verifier` independence is structural:** it receives only `{claim, file:line, source module, confidence, exclude-set}` + a refute-first posture — never the finder's rationale; **a lens never verifies its own finding.**
- **The Verify panel's fan-out is bounded by the CATALOG, and its guard is deliberately partial (0041 S10b, 2026-08-17).** `dimensions` is validated for membership only, so it is de-duplicated **once at the boundary**, feeding the roster and the audited-module list from the **same array** — they pair by index, and `coverageGaps` names the wrong module as unrun if they diverge. The dedupe is non-mutating (`build-item.js` passes its named list through with no copy) and idempotent. The panel guard wraps the **lens and yagni thunks only**: it returns `null` **in position** (any filter/compact/settle reshape breaks `splitPanelResults`' index arithmetic), and it must **never** cover the trust-surface honesty thunk — the guard's message is false for a judge (no coverage gap, no forced `CHANGES_REQUIRED`). **Unguarded is not loud, so the loudness lives at the RESULT instead (RESOLVED 2026-08-19).** Measured 2026-08-17, `parallel()` swallows `judgeOutcome`'s two-failure throw either way, so the thunk stays silent; an unrun trust-surface honesty judge is caught AFTER the split — it is **logged**, it sets **`panelDegraded`**, and it serializes as **`{ couldNotRun: true }`**, mirroring `yagni`. It **degrades, never blocks**: `finalVerdict` is unchanged. The `hasHonesty &&` guard on that check is load-bearing — with `trustSurface=false` a null `honesty` is the legitimate not-asked-for case, not a failure. **Do not "simplify" either to a blanket map over `panelTasks`.**
- **An unrun trust-surface honesty judge DEGRADES the panel; it never blocks (2026-08-19, RM-4).** `engine/verify.js` computes `honestyUnrun = hasHonesty && honesty == null` -- it is LOGGED, it sets `panelDegraded`, and it serializes as `{ couldNotRun: true }`, mirroring `yagni`; **`finalVerdict` is UNCHANGED** (degrade, not block -- blocking was never approved). The `hasHonesty &&` guard is load-bearing: with `trustSurface=false` a null `honesty` is the legitimate not-asked-for case, and folding the two would mark every non-trust run degraded. Closes the 0041 S10b measurement in place -- the sentence that recorded it as *routed, not fixed* was amended, not left standing.
