- **`finding-verifier` independence is structural:** it receives only `{claim, file:line, source module, confidence, exclude-set}` + a refute-first posture — never the finder's rationale; **a lens never verifies its own finding.**
- **The Verify panel's fan-out is bounded by the CATALOG, and its guard is deliberately partial (0041 S10b, 2026-08-17).** `dimensions` is validated for membership only, so it is de-duplicated **once at the boundary**, feeding the roster and the audited-module list from the **same array** — they pair by index, and `coverageGaps` names the wrong module as unrun if they diverge. The dedupe is non-mutating (`build-item.js` passes its named list through with no copy) and idempotent. The panel guard wraps the **lens and yagni thunks only**: it returns `null` **in position** (any filter/compact/settle reshape breaks `splitPanelResults`' index arithmetic), and it must **never** cover the trust-surface honesty thunk — the guard's message is false for a judge (no coverage gap, no forced `CHANGES_REQUIRED`). **Unguarded is not loud, so the loudness lives at the RESULT instead (RESOLVED 2026-08-19).** Measured 2026-08-17, `parallel()` swallows `judgeOutcome`'s two-failure throw either way, so the thunk stays silent; an unrun trust-surface honesty judge is caught AFTER the split — it is **logged**, it sets **`panelDegraded`**, and it serializes as **`{ couldNotRun: true }`**, mirroring `yagni`. It **degrades, never blocks**: `finalVerdict` is unchanged. The `hasHonesty &&` guard on that check is load-bearing — with `trustSurface=false` a null `honesty` is the legitimate not-asked-for case, not a failure. **Do not "simplify" either to a blanket map over `panelTasks`.**

The `hasHonesty &&` guard is load-bearing: with `trustSurface=false` a null `honesty` is the legitimate not-asked-for case, and folding the two would mark every non-trust run degraded.
